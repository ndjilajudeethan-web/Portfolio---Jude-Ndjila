### Technologies utilisées

- Marquage HTML5 sémantique
- Propriétés CSS personnalisées
- Flexbox
- CSS Grid
- Workflow mobile-first 

### Ce que j'ai appris

```html
<h1 class= "page_contenu-h1">Social Media <span style="color: #fecc6a; font-weight: bold; font-size: 50px;">10x</span> Faster with AI</h1>
```

```css
.fier-de-ce-css {
  grid-template-areas:
        "sidebar-top main main ads"
        "sidebar-bottom center1 center2 ads"
        "sidebar-bottom  footer-stat footer-bottom-right footer-bottom-right";
}
```

### Développement continu

J’aimerais m’améliorer et continuer à utiliser les propriétés grid et grid-template.
